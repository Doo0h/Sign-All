# Frontend

기업·직무 선택 → 자기소개서 입력·분석 → 질문 확인 → 관련 수어 자료 참고 → 텍스트 답변 → AI 피드백 화면을 구현할 위치입니다.

현재는 설계 준비 단계이며 실행 가능한 앱은 없습니다. 프레임워크·실행 명령은 기술 스택 결정 후 추가합니다.

API 계약: [설계 초안](../docs/api-draft.md). 로딩·빈 결과·오류 상태를 화면에 표시합니다.

## 실행 (3주차 초안, 프레임워크 없는 HTML/JS)

```
cd backend && npm start          # http://127.0.0.1:3001
cd frontend && node serve.js     # http://localhost:5173
```

화면 흐름·API 연결표: [docs/screen-flow.md](../docs/screen-flow.md)
