# Frontend

Sign-All의 텍스트 면접 연습 UI입니다. 별도 프레임워크나 패키지 설치 없이 Node.js 24로 실행합니다.

5주차 확장: 기업 카드 검색·선택, 문서 텍스트 불러오기, 외부 AI 전송 확인, 공식 수어 사전 링크를 제공합니다. 입사지원 사이트 형태의 **면접 연습 서비스**이며 실제 채용 접수를 하지 않습니다.

Docker 실행은 저장소 루트에서 `docker compose up -d --build --wait`, 접속은 http://localhost:8080 입니다. 프론트의 `/api`가 backend로 프록시되므로 배포 시 API 주소를 사용자 PC의 localhost로 바꾸지 않습니다.

직접 실행 시 문서 추출을 사용하려면 backend의 Python 의존성을 설치하세요. 프론트 테스트는 `npm ci` 후 Node 24에서 `npm test -- --test-concurrency=1`로 실행합니다.

## 실행

저장소 루트에서 터미널을 각각 열어 실행합니다.

```powershell
cd backend
npm start
```

```powershell
cd frontend
node serve.js
```

화면: http://127.0.0.1:5173
백엔드: http://127.0.0.1:3001

## 화면 흐름

시작 안내 → 기업·직무 선택 → 자기소개서 입력·분석 → 질문 목록 → 질문·답변·피드백 → 연습 종료

- 왼쪽 5단계 진행 안내, 모바일에서는 상단 단계 표시
- 밝은 배경과 청록색 주요 버튼, 질문 카드와 입력 안내
- 수어 자료 없음·오류·세션 만료 상태 안내
- 처리 중 입력 잠금, 답변 변경 시 이전 피드백 초기화
- 토큰과 입력은 메모리에만 보관, 종료 시 초기화
- demo 배너로 가상 자료와 규칙 기반 응답 구분

API는 [현재 백엔드 계약](../docs/backend-contract.md)을 따릅니다.
상세 흐름 초안은 [화면 흐름 문서](../docs/screen-flow.md)를 참고하세요.
실제 AI·수어 자료 연동과 개인정보 고지의 운영 적합성은 별도 검토 대상입니다.
