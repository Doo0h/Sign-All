# 수어 자료 후보 조사표

- 담당자: 모소연
- 작업 브랜치: `sign-data`
- 활동 회차: 4주차 조사 준비
- 상태: 실제 생성 질문 미전달 — 질문 기반 조사 미착수

## 1. 조사 목적 및 주의사항

이 문서는 실제 생성된 면접 질문을 전달받은 뒤 핵심 키워드와 관련 수어 자료를 조사하기 위한 기록표다.

현재 실제 질문을 전달받지 않았으므로 질문, 키워드, 표제어, 개별 상세 페이지, 영상 주소 또는 매칭 결과를 임의로 채우지 않는다. 아래 표는 조사 준비용 템플릿이다.

질문 전체를 수어로 번역하지 않는다. 질문에서 검토된 핵심 키워드와 의미가 맞는 기존 수어 자료를 참고 자료로 연결하는 범위로 제한한다.

| 제공기관 | 문화체육관광부 |

## 3. 실제 질문 및 키워드 기록

질문 전달 상태: **미전달**

| 질문 ID | 실제 생성 질문 원문 | 질문 출처·버전 | 핵심 키워드 1 | 핵심 키워드 2 | 핵심 키워드 3~5 |
|---|---|---|---|---|---|
| 미작성 | 실제 질문 전달 후 입력 | 미확인 | 미작성 | 미작성 | 미작성 |

질문을 전달받은 뒤 질문별 핵심 키워드를 3~5개 선정한다. 질문이 전달되기 전에는 예시 문항을 실제 질문으로 기록하지 않는다.

## 4. 키워드별 수어 자료 후보 조사표

| 질문 ID | 핵심 키워드 | 질문 문맥상 의미 | 검색어 | 검색 결과 표제어 | 원본 식별자 | 사전 의미·용례 | 의미 판정 |
|---|---|---|---|---|---|---|---|
| 미작성 | 미작성 | 미작성 | 미작성 | 미확인 | 미확인 | 미확인 | 조사 전 |

의미 판정 선택 기준:
- `일치 검토 완료`
- `추가 검토 필요`
- `의미 불일치`
- `검색 결과 없음`
- `전문가 검토 필요`
- `조사 전`

검색 결과에 여러 한국어 대응 표현이 함께 제시되면 각각의 표현과 용례를 별도로 검토한다. 표제어 묶음에 포함되었다는 이유만으로 모든 표현을 같은 의미로 취급하지 않는다.

## 5. 상세 페이지·영상 확인표

| 검색 표제어 | 개별 상세 페이지 URL | 영상 제공 여부 | 실제 영상 URL | 재생 확인 | 확인일 |
|---|---|---|---|---|---|
| 미확인 | 미확인 | 미확인 | 미확인 | 미확인 | 미기록 |

기록 기준:
- 상세 페이지 URL은 실제 페이지를 열어 확인한 경우에만 기록한다.
- 영상 제공 여부는 `있음`, `없음`, `미확인`으로 구분한다.
- 실제 영상 URL은 원본에서 확인한 주소만 기록한다.
- 재생 확인은 실제 브라우저 등에서 재생을 시도한 결과로 기록한다.
- 페이지에 영상이 표시되는 것과 직접 영상 URL을 확인한 것은 구분한다.
- 확인일은 실제 확인 작업을 수행한 날짜만 입력한다.

## 6. 출처 및 이용 조건 확인표

| 자료·영상 식별 정보 | 출처 및 저작권자 | 외부 링크 제공 | 외부 삽입 | 다운로드·저장 | 재배포 | 확인 근거·비고 |
|---|---|---|---|---|---|---|
| 미확인 | 미확인 | 미확인 | 미확인 | 미확인 | 미확인 | 개별 조건 확인 필요 |

이용 조건 상태:
- `확인됨`
- `허용되지 않음`
- `조건부 허용`
- `확인 필요`

공공데이터포털의 이용허락범위와 개별 사전 자료·영상의 저작권 조건을 구분한다. 링크 접근이 가능하다는 사실만으로 영상 삽입, 다운로드 또는 재배포가 허용된다고 판단하지 않는다.

## 7. 최종 매칭 검토표

| 질문 ID | 키워드 | 후보 표제어 | 질문 문맥과 의미 비교 근거 | 검토자 | 최종 판정 | 백엔드 전달 |
|---|---|---|---|---|---|---|
| 미작성 | 미작성 | 미확인 | 미작성 | 미확인 | 조사 전 | 보류 |

최종 판정 기준:
- `검토 완료`: 의미와 용례가 질문 문맥에 부합한다고 확인된 상태
- `전문가 확인 필요`: 의미 판단이 어렵거나 복수 표현의 구분이 필요한 상태
- `매칭 불가`: 의미가 일치하지 않는 상태
- `자료 없음`: 관련 자료를 찾지 못한 상태
- `영상 미확인`: 표제어는 확인했지만 영상 제공 여부 또는 주소가 확인되지 않은 상태
- `이용 조건 미확인`: 서비스 활용 가능 여부를 판단할 수 없는 상태

백엔드의 키워드 검색 결과 `candidate`는 의미 검증 완료를 뜻하지 않는다. 의미 검토 및 이용 조건이 확인되지 않은 자료를 검증 완료 자료로 전달하지 않는다.

## 8. 내부 데이터 반영 기준

팀 내부 관리 형식:
- 필수: `id`, `sourceId`, `term`, `keywords`
- 선택: `meaning`, `sourcePageUrl`, `videoUrl`

주의:
- 이 항목들은 Sign-All 내부 관리 형식이며 외부 API 원본 필드명이 아니다.
- `sourceId`는 `sources` 테이블의 내부 출처 ID다. 사전 원본 식별자는 조사 기록의 `originalId`로 별도 관리한다.
- `meaning`, `sourcePageUrl`, `videoUrl`은 실제 확인한 경우에만 입력한다.
- 영상 URL과 이용 조건이 확인되지 않았다면 `videoUrl`을 임의로 채우지 않는다.

## 9. 5주차 진행 체크리스트

- [ ] AI 담당자로부터 실제 생성 질문 수신
- [ ] 질문 원문 및 출처·버전 기록
- [ ] 질문별 핵심 키워드 3~5개 선정
- [ ] 키워드별 공식 사전 검색
- [ ] 표제어 및 한국어 대응 표현 기록
- [ ] 개별 상세 페이지 주소 확인
- [ ] 영상 제공 여부 확인
- [ ] 실제 영상 URL 확인(제공되는 경우)
- [ ] 영상 재생 확인
- [ ] 질문 문맥과 수어 의미·용례 비교
- [ ] 불확실한 항목 전문가 검토 대상으로 분류
- [ ] 출처 및 링크·삽입·다운로드·재배포 조건 확인
- [ ] 확인된 자료만 내부 데이터 형식으로 정리
- [ ] 백엔드 담당자와 전달 형식 및 상태값 협의

- 개별 상세 페이지 확인: 미착수
- 영상 및 재생 확인: 미착수
