# 수어 자료 조사 및 키워드 연결 기준

## 1. 공식 수어 자료 제공처 및 이용 조건

### 1.1 조사 대상

| 항목 | 확인 내용 |
|---|---|
| 자료명 | 문화체육관광부_일상생활 수어 |
| 제공기관 | 문화체육관광부 |
| 공식 출처 | https://www.data.go.kr/data/15105152/openapi.do |
| 실제 자료 사전 | 국립국어원 한국수어사전 |
| API 유형 | LINK |
| 제공 형식 | JSON, XML |
| 이용 비용 | 무료 |
| 공공데이터포털 이용허락범위 | 제한 없음 |
| 운영 단계 | 심의 승인 필요 |

### 1.2 자료 제공 및 이용 조건

공공데이터포털의 공식 안내에 따르면 해당 API는 국립국어원의 일상생활 수어 정보를 제공하며, 수어 명칭, 수형 설명, 이미지, 내용 등의 정보를 포함한다.

국립국어원 한국수어사전의 저작권 정책도 별도로 확인하였다.

- 일반 텍스트 및 이미지 자료: 크리에이티브 커먼즈 저작자표시-비영리-변경금지 2.0 대한민국 라이선스 적용 대상
- 저작자 표시가 필요하며 자료를 변경하지 않고 이용해야 함
- 동영상 자료: 개별 영상의 저작권 정책을 별도로 확인해야 함
- 일부 일상생활 수어 영상은 국립국어원이 저작권을 소유하지 않으며, 해당 영상에는 위 크리에이티브 커먼즈 라이선스가 적용되지 않음

따라서 공공데이터포털의 이용허락범위와 개별 사전 영상의 이용 조건을 구분한다. 영상 다운로드 및 재배포는 개별 이용 조건 확인 전까지 진행하지 않는다.

### 1.3 조사 결과 및 미확인 사항

| 조사 항목 | 결과 |
|---|---|
| 공식 제공처 | 확인 |
| 데이터 제공 형식 | JSON, XML 확인 |
| 공식 안내 데이터 항목 | 수어 명칭, 수형 설명, 이미지, 내용 등 확인 |
| 실제 API 응답 필드명 | 미확인 |
| 실제 API 응답 데이터 | 미확인 |
| API 인증 및 운영 신청 조건 | 추가 확인 필요 |
| 영상 주소의 API 제공 여부 | 미확인 |
| 개별 영상 다운로드 및 재배포 조건 | 개별 확인 필요 |

※ 공공데이터포털의 API 안내와 국립국어원 사전의 실제 검색 결과는 확인했으나, API를 직접 호출하여 원본 응답을 확보한 것은 아니다.

## 2. 시연 키워드 후보 및 실제 사전 검색 결과

국립국어원 한국수어사전의 검색 결과에서 면접 질문과 관련된 표현을 확인하였다.

검색 결과에서 여러 한국어 대응 표현이 하나의 표제어 묶음으로 제시되는 경우가 있으므로, 개별 표현을 동일한 수어 의미로 단정하지 않는다.

### 2.1 키워드 후보

| 키워드 | 시연 질문 후보 문맥 | 선정 이유 |
|---|---|---|
| 협력 | 팀원과 함께 목표를 달성한 경험 | 팀워크 및 공동 목표 달성 역량 |
| 도움 | 다른 사람을 도와주거나 지원한 경험 | 협력 및 지원 역량 |
| 질문 | 질문을 통해 문제를 해결하거나 정보를 확인한 경험 | 의사소통 및 정보 확인 능력 |

※ 위 질문 문맥은 키워드 선정을 위한 예시이며, 실제 팀 시연 질문의 최종 문구는 별도 확인이 필요하다.

### 2.2 실제 사전 검색 결과

| 검색 키워드 | 확인된 사전 표제어 및 표현 | 의미 검토 | 확인 상태 |
|---|---|---|---|
| 협력 | 같다, 같이, 함께 등이 포함된 표제어 묶음 | 함께한다는 표현과 관련되지만 협력이라는 의미와 완전히 동일하다고 판단할 수 없음 | 추가 검토 |
| 도움 | 돕다, 도와주다, 지원(하다), 도움을 받다 | 타인을 돕거나 지원하는 의미와 관련된 표현 확인 | 후보 발견 |
| 질문 | 묻다, 질문하다, 질문을 받다 | 질문하거나 질문을 받는 상황과 관련된 표현 확인 | 후보 발견 |

검색 결과에서 확인한 표제어 묶음과 한국어 용례는 국립국어원 한국수어사전의 검색 결과에 제시되어 있다.

검색 결과 페이지:
https://sldict.korean.go.kr/demondicKor/signKorSearch.do

### 2.3 자료 확인 결과

| 확인 항목 | 결과 |
|---|---|
| 표제어 및 관련 표현 | 일부 검색 결과 확인 |
| 의미 및 한국어 용례 | 일부 확인 |
| 개별 사전 항목 상세 페이지 주소 | 미확인 |
| 개별 영상 제공 여부 | 항목별 확인 필요 |
| 실제 영상 URL | 미확인 |
| 영상 재생 여부 | 미확인 |
| 질문과 수어 의미의 최종 일치 여부 | 전문가 검토 필요 |

국립국어원 사전 안내에서는 수어 표제어를 영상으로 확인할 수 있으며, 변이형 영상과 한국어 대응 표현, 수어 용례 등의 정보를 제공한다고 설명한다.

다만 이번 검색 결과만으로는 각 후보 항목의 실제 영상 주소와 재생 가능 여부를 확인하지 못했다.

## 3. 질문과 수어 자료의 연결 기준

1. 시연 면접 질문에서 핵심 키워드를 추출한다.
2. 핵심 키워드를 국립국어원 한국수어사전에서 검색한다.
3. 검색 결과의 표제어와 한국어 대응 표현을 확인한다.
4. 사전의 의미 및 용례와 면접 질문의 문맥을 비교한다.
5. 의미가 일치하는지 검토하고 매칭 근거를 기록한다.
6. 의미 판단이 어렵다면 수어에 능숙한 검토자의 확인을 요청한다.

### 예외 처리

| 유형 | 처리 기준 |
|---|---|
| 의미 일치 | 검토 후 참고 자료로 연결 |
| 의미가 유사하지만 불확실함 | 추가 검토 후 연결 여부 결정 |
| 동음이의어 | 질문 문맥과 사전 의미를 비교하여 구분 |
| 복수 표현 | 각 표현을 개별적으로 검토 |
| 의미 불일치 | 연결하지 않음 |
| 자료 없음 | 빈 목록 및 미제공 안내 |
| 영상 미확인 | 영상 주소를 입력하지 않음 |
| 재생 실패 | 자료 존재 여부와 재생 오류를 구분 |

검색 결과가 존재하더라도 키워드 일치만으로 의미 검증이 완료되었다고 판단하지 않는다.

## 5. 미확인 사항 및 후속 확인

- 공식 API를 직접 호출하여 실제 JSON/XML 응답 항목과 원본 식별자를 확인해야 한다.
- 검색된 표제어별 개별 상세 페이지 주소를 확인해야 한다.
- 각 표제어의 실제 수어 영상 제공 여부와 영상 URL을 확인해야 한다.
- 영상별 저작권 및 외부 링크·삽입·다운로드·재배포 조건을 확인해야 한다.
- 면접 질문의 실제 문맥과 수어 표현이 일치하는지 수어에 능숙한 검토자의 확인이 필요하다.
- 확인된 자료만 내부 관리 형식인 id, sourceId, term, keywords에 반영한다.
- meaning, sourcePageUrl, videoUrl은 실제 확인한 경우에만 기록한다.

확인되지 않은 자료는 임의로 생성하거나 확정된 매칭으로 처리하지 않는다.
