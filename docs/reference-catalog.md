# 기업·수어 시작 자료

2026-11-11에 공식 페이지를 확인하고 `data/reference-starter.json`에 기업 3개, 일반 연습 직무 3개, 수어 사전 항목 5개를 추가했다.

기업 자료는 NAVER 회사 소개, 카카오 서비스 소개, 삼성전자 회사 소개의 짧은 요약과 출처 링크다. 현재 채용 중이라는 의미가 아니며 공고·마감일·급여·채용 기준을 만들지 않는다. 회사 로고와 사진은 복제하지 않았다.

직무와 연습 요소는 Sign-All이 작성한 일반 연습 기준이다. 백엔드는 API·데이터·오류 해결, 프론트엔드는 화면·접근성, 데이터·AI는 실험과 결과 한계를 이야기하도록 돕는다. 공식 NCS 능력단위나 특정 기업 평가 기준이 아니다.

## 수어 항목 확인

한국수어사전의 일상생활 검색에서 도움·질문·경험·문제·해결을 조회하고 원본 ID 5447, 11634, 6927, 7320, 5294의 상세 페이지를 HTTP 200으로 확인했다. 플레이어 영역과 수형 설명이 존재한다. 자료별 원문 주소는 JSON에 보존했다.

`verificationStatus=verified`는 출처 페이지 및 항목 존재 확인 범위다. **질문 문맥과 수어의 의미 일치를 검증한 것이 아니다.** 각 수어 레코드에는 `semanticStatus=unreviewed`, `playbackStatus=not-tested`, `mediaUsage=source-link-only`를 함께 둔다. 제품에서는 참고 후보와 공식 사전 열기만 표시한다.

사전의 영상·이미지를 다운로드, 복제, 외부 삽입하지 않는다. [공식 저작권 정책](https://sldict.korean.go.kr/front/main/copyRightPolicy.do)에 따라 개별 영상의 권리 확인이 필요하다. 원문에서 재생하더라도 적절한 의미인지 수어에 능숙한 검토자가 확인해야 한다.

이전 조사에서 개발 검색의 발개지다, 관심 검색의 무관심처럼 문맥이 다른 결과는 계속 제외한다. 문자열 부분 일치만으로 새 항목을 자동 수집하지 않는다.

## 재현과 갱신

```powershell
cd backend
node scripts/import-data.js ../data/reference-starter.json
```

동일 ID를 다시 가져오면 갱신된다. 원문 URL·확인일·검증 범위를 함께 갱신한다. 일반 직무를 기업별 실제 채용 직무로 표시하지 않는다. Docker 기본 설정은 이 자료를 가져오고 `REFERENCE_MODE=live`, AI는 `APP_MODE=demo`로 분리한다.
