# 실제 채용 공고 연결

Greenhouse 공식 Job Board API 및 카카오·네이버 공식 채용 사이트의 공개 GET 조회를 사용합니다. 추가 API 키는 필요하지 않습니다. https://docs.greenhouse.io/job-board.html

연결 출처: 카카오(kakao), NAVER(naver), 쿠팡(coupang), 몰로코(moloco), 센드버드(sendbird), 라이엇게임즈(riotgames), Fender(fender), 2K(2k). Greenhouse는 한국 근무지역이 명시된 게시 공고를 제공합니다. 카카오·네이버는 공식 국내 채용 사이트의 진행 중 공고를 제공하며 근무지가 명시되지 않으면 원문 확인으로 표시합니다. 전국 모든 기업이나 모든 계열사를 포괄하지 않습니다. 인재풀·채용관심등록 공고는 제외합니다.

카카오는 https://careers.kakao.com/jobs 의 공개 `job-list`를 4개 직군별로 조회하고 `job-detail`로 확인합니다. 비공개·종료·미사용 공고를 제외하고 한국 시간 기준 마감일을 처리합니다. 네이버는 https://recruit.navercorp.com/rcrt/list.do 의 공개 `loadJobList.do` 목록과 공고 상세 페이지를 사용합니다. 이 두 사이트의 조회 형식은 별도 공개 API 계약이 아니므로 변경 시 어댑터 수정이 필요합니다. 구조를 읽지 못하면 공고를 임의 생성하지 않고 연결 실패로 표시합니다.

## 사용

면접 연습 시작 → 채용공고 → 기업 탭/직무/지역/경력 검색 및 마감·갱신 정렬 → ‘공고 선택’ → 상세 확인 → ‘이 공고로 면접 연습’ → 자기소개서 분석 → 예상 질문. 실제 채용 연결 모드에서는 별도의 기업·직무 직접 선택을 표시하지 않습니다. 목록은 페이지당 10개이며 번호로 페이지를 이동합니다. 기업 식별 이미지는 `frontend/logos/SOURCES.md`에 출처를 기록하고 이미지가 없거나 로드에 실패하면 첫 글자로 대체합니다.

공고 선택 시 담당업무·자격요건을 포함하는 본문을 최대 6,500자 가져옵니다. 질문 생성 직전에 공고를 재확인하고, 자기소개서 분석 및 공고 본문을 AI 입력으로 전달합니다. 본문에는 잘린 내용이 있을 수 있어 원문 확인이 필요합니다. 실제 지원은 원문 사이트에서만 진행합니다.

## 최신성 및 범위

- 목록은 조회 시 갱신하며 서버 메모리에서 최대 15분 캐시합니다. 사라진 공고는 다음 갱신에 제외합니다.
- 마감일이 제공되고 지났으면 제외합니다. 미제공은 ‘마감일 원문 확인’으로 표시하며 임의 날짜를 만들지 않습니다.
- 직무·경력 필터는 공고 제목 기반 분류입니다. 필수 경력이나 지원 자격을 확정하는 정보가 아닙니다.
- 일부 기업 연결 실패는 화면에 표시하며 해당 기업의 오래된 목록을 정상 공고처럼 반환하지 않습니다. 전체 실패는 재시도 가능한 오류로 표시합니다.
- 외부 사이트의 링크·본문은 사용자 입력과 동일하게 데이터로만 취급합니다. HTML은 텍스트로 변환하고 외부 URL은 HTTPS만 허용합니다.

## 운영

Docker compose는 `POSTINGS_ENABLED=true`로 실행합니다. Node 직접 실행 시 같은 환경변수를 설정하세요. 조회 API는 `GET /api/postings?q=&company=&category=&region=&experience=&offset=0`, 선택은 세션을 요구하는 `POST /api/postings/select`입니다. 기업 목록은 `backend/src/postings.js`의 고정 allowlist에서 관리합니다. 공고 본문·선택 정보는 메모리에서만 유지합니다.

고용24는 기업회원 자격과 인증키 심사가 필요하므로 이번 연결에는 포함하지 않았습니다. 향후 승인된 계정으로 확장할 수 있습니다. https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do
