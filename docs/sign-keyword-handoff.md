# 수어 담당 전달용 — 가상 면접 질문·키워드 후보 (4주차)
> 5주차: 같은 모의 질문 버전으로 사전 조사를 진행한다. 실제 모델 출력은 아직 없으며 로컬 모델 평가 후 새 질문 버전을 전달해야 한다.

- 수신 대상: 모소연 (수어 자료 담당)
- 작성: AI 기능 담당 / 2026-11-10
- **상태: 전달 준비용 문서. 실제 메시지 발송 완료 아님.**
- 모든 자기소개서는 개인정보가 없는 **팀 작성 가상 입력**, 질문도 **사람이 만든 모의 기대 질문**이다. 모델의 실측 출력이나 기업 기출이 아니다.
- 수어 영상/API에서 일치하는 표제어가 실제로 존재한다는 뜻이 아니다. 문맥상 의미 확인과 출처·영상 이용 조건 검토는 수어 담당자가 수행한다.

| ID | 질문 | 핵심 키워드 후보 |
|---|---|---|
| S01-Q1 | 팀원들과 남은 작업을 나눌 때 어떤 기준을 고려했나요? | 팀원, 역할 분담 |
| S01-Q2 | 진행 상황을 공유하고 점검표를 사용한 방법을 설명해 주세요. | 진행 상황, 공유, 점검표 |
| S02-Q1 | API 응답 실패를 조사하면서 어떤 로그를 비교했나요? | API, 로그, 오류 |
| S02-Q2 | 입력값을 바꿔 오류를 재현한 과정을 설명해 주세요. | 재현, 입력값, 문제 해결 |
| S03-Q1 | 개발에 관심을 갖게 된 계기를 설명해 주세요. | 개발, 관심 |

## 연동 주의
- `GET /api/signs?keyword=...`가 후보를 반환해도 의미 일치를 보장하지 않는다.
- 다의어/전문 용어는 질문 문맥과 수어 의미를 대조한 후 채택한다.
- 영상 미확보 시 텍스트 질문과 답변 연습은 계속 가능해야 한다.
- 정식 모델 생성 결과가 확보되면 질문·키워드를 새 버전으로 재전달한다.
