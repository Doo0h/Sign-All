## 이용 조건과 전달 계약

[사전 저작권 정책](https://sldict.korean.go.kr/front/main/copyRightPolicy.do)은 일반 텍스트·이미지의 CC BY-NC-ND 2.0 KR 안내와 개별 영상 권리 확인을 구분한다. 이번 항목의 외부 링크 공개·삽입·다운로드·재배포 허용 여부는 확인 필요다. 이 문서의 링크는 팀 조사 근거이며 서비스 사용 허가를 뜻하지 않는다.

`signs.sourceId`는 내부 `sources.id`를 참조한다. 사전의 `originalId`와 다르다. 검토 완료 후 내부 출처 레코드를 만들고 연결해야 한다. 이번 조사 레코드는 import 데이터로 넣지 않으며 `verified=true`로 올리지 않는다. 따라서 demo 수어 API는 기존처럼 빈 목록을 반환한다.
