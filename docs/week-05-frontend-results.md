# 5주차 프론트엔드 결과

강지모 / frontend / 2026-11-11.

기존 로컬 UI 작업을 반영해 시작 → 기업·직무 → 자기소개서 분석 → 질문 목록 → 답변·피드백 → 종료 화면을 연결했다. 사이드 단계 표시, 모바일 대응 CSS, 명시적 라벨과 상태 안내를 유지한다.

서버 health로 demo/로컬 AI/외부 AI 모드를 안내한다. 요청 중 입력·버튼을 잠그며, 자기소개서·답변 수정 시 오래된 결과를 무효화한다. 만료 응답은 토큰과 입력을 즉시 삭제한다. 종료 요청이 연결 오류로 실패하면 성공 화면으로 넘어가지 않고 재시도를 허용한다. 최초 목록 조회 실패 시 이미 만든 세션을 재사용한다.

## 실행한 검증

Node v24.22.2, `cd frontend; npm ci; npm test`(실제 실행은 동일 버전 node --test).

jsdom + 실제 임시 HTTP demo 백엔드를 사용하는 시험 4/4 통과:

1. 시작부터 종료까지 전체 흐름, 빈 수어 안내, 답변 수정, storage 미사용
2. 지연 응답 동안 중복 요청 차단, 입력 변경 시 분석 무효화
3. 410 만료 시 토큰·원문 초기화
4. 종료 네트워크 실패 후 재시도

브라우저 제어 호스트 연결 불가로 실제 렌더링·모바일 폭·키보드 이동에 대한 시각 검수는 미완료다. DOM 시험은 브라우저 검수나 실제 AI 품질 시험을 대체하지 않는다. 이 시험의 데이터는 가상 입력이다.
