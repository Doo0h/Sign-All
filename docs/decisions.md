이 문서는 제안을 팀 확정 사항으로 오해하지 않도록 상태를 기록합니다. 문서 반영은 팀 회의 승인·구현·자료 검증 완료를 의미하지 않습니다.

| 항목 | 상태 |

| 기술 스택·영구 저장·로그인 | 미정, 로그인·기록 조회는 필수로 확정하지 않음 |

## 후속 결정

- 4주차: 실제 실행 결과로 프롬프트·출력 검증·재시도 정책 보완
- 4~5주차: 실제 조회·갱신 요구를 보고 저장 방식 최종 선택
- 5~6주차: 수어 제공·이용 조건 확인 결과에 따른 링크/재생 방식
- 7~8주차: 외부 의견을 근거로 핵심 오류·안내 우선 개선

## 실행 가능한 백엔드 첫 구현 — 구현 기준안

기존 상태표는 설계 시점 기록입니다. 아래는 후속 코드 추가 상태이며 팀 최종 합의나 원본 확보를 의미하지 않습니다.

- Node.js 24.x + 내장 SQLite로 참조자료 DB·서버·테스트를 구현했습니다. 다른 스택으로 교체 가능하며 외부 패키지는 없습니다.
- 맥락 연결은 대안 B(서버의 임시 세션 참조)를 선택했습니다. 원문·답변·AI 결과의 영구 DB 저장은 하지 않습니다.
- 세션 토큰은 X-Session-Token 헤더로 전달하며 결과 소유권·만료를 확인합니다. 로그인 기능은 추가하지 않았습니다.
- demo는 가상 기업·직무와 규칙 응답, live는 검토된 자료와 설정한 AI HTTP 어댑터를 사용합니다. 실제 공급자·수어 API 연동 검증은 미완료입니다.
- 실제 API 계약·제한·실행법은 [backend-contract.md](backend-contract.md)와 [backend README](../backend/README.md)에 기록했습니다.
- 공식 원본 샘플·시연 직무·수어 영상·이용 조건 검증, 프론트 연동, 외부 자문은 후속 작업입니다.
