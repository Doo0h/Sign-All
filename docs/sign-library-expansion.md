# 수어 자료실 확장 (2026-11-12)

기존 5개에 회사, 준비, 계획, 노력, 성공, 실패, 책임, 약속, 시간, 배우다, 생각, 설명, 이해, 대화, 직장, 취업 16개를 추가했습니다. 국립국어원 한국수어사전 상세 페이지의 표제어 포함 여부와 접근 가능 여부를 확인했습니다.

총 21개는 **참고 후보**이며 면접 문맥의 의미 검수나 영상 재생 검증을 완료한 자료가 아닙니다. 전체 문장 번역 기능도 아닙니다. 영상과 이미지는 복제하지 않고 원문 링크로 제공합니다. 검색에서 유사한 단어가 나왔다는 이유만으로 다른 뜻의 표제어를 추가하지 않았습니다.

화면 상단 **수어 자료실**에서 검색하고 12개씩 더 볼 수 있습니다. 면접 작성 내용은 자료실을 열고 닫아도 유지됩니다. 자료는 `data/reference-starter.json`, 조회 API는 `GET /api/signs/catalog?q=회사&offset=0`입니다.

## 무료 외부 AI 준비

Groq 연결 코드는 이미 포함되어 있습니다. 무료 계정에도 호출 한도가 있으며 계정 콘솔의 한도를 확인해야 합니다. 채팅에 노출한 키는 폐기하고 새 키를 저장하세요.

1. https://console.groq.com/keys 에서 키를 발급합니다.
2. 저장소 루트의 `.env`에 `AI_API_KEY` 값을 직접 저장합니다. 이 파일은 Git 추적 대상에서 제외됩니다.
3. `AI_PROVIDER=groq`, `APP_MODE=live`로 설정합니다.
4. `docker compose up -d --build --wait`로 다시 실행합니다.
5. 화면의 외부 전송 안내를 확인하고 먼저 가상 자기소개서로 시험합니다.

키가 없거나 유효하지 않으면 실제 AI 시험을 완료했다고 판단할 수 없습니다. 기본 시연 모드는 외부 호출 없이 동작합니다.
