# 5주차 확장 구현 결과

2026-11-11. 한 사람이 전체 작업을 수행할 수 있도록 담당 브랜치별 코드와 배포 경로를 구현했다. 기존 5주차 통합 결과 이후의 추가 작업이다.

| 브랜치 | 추가 구현 |
|---|---|
| ai | Groq 무료 플랜 연결 프리셋, JSON 응답 요청, 무료 한도 오류 안내, 자동 유료 대체 없음 |
| sign-data | 공식 기업 소개 3개·일반 연습 직무 3개·공식 수어 사전 원문 링크 5개, 검증 범위 기록 |
| frontend | 입사지원 준비 형태의 UI, 기업 검색 카드, 파일 업로드와 편집, 외부 AI 안내, 같은 출처 API 프록시, Dockerfile |
| backend | 문서 추출 API·프로세스 제한·저장 방지, 참고자료 모드 분리, Docker Compose·HTTPS 팀 접속 구성, CI |

## 실제 확인

- Node v24.22.2: backend 31/31, frontend 8/8 시험 통과.
- Python 3.11: 합성 HWP 5·PDF·HWPX·DOCX, 암호·XML 엔터티·압축 확장 제한 시험 4/4 통과.
- 사용자가 제공했던 5주차 HWP 문서에서 2,093자 추출 확인. 원본·추출 내용은 Git이나 외부 AI에 전송하지 않았다.
- Docker Desktop Linux engine: 두 이미지 빌드, 두 컨테이너 healthy 확인.
- http://127.0.0.1:8080 을 통해 기업 3개·직무 3개를 사용하는 분석 → 질문 → 피드백 → 종료 smoke 통과.
- 같은 프록시·Docker 경로로 TXT/HWP/HWPX/DOCX/PDF 합성 파일 5종 추출과 수어 원문 링크 조회 통과.
- Caddy 설정을 가상 도메인·시험용 해시로 validate하여 문법·구성 통과. 실제 도메인 인증서 발급은 미수행.

## 완료로 표시하지 않는 항목

- 실제 외부 AI 추론: Groq 키가 없어 미수행. API 형식은 mock 검증만 했다.
- 원격 공개 배포: 사용자가 서버 미보유로 답했다. 계정·도메인·접속 정보가 없으므로 로컬 Docker 실행과 배포 준비까지만 완료했다.
- 수어 영상 확보·임베드·문맥 의미 검증: 미수행. 확인한 공식 원문 링크만 참고 후보로 제공한다.
- 화면 시각 검수: 브라우저 호스트 연결이 불가했고 네이티브 캡처도 대상 미리보기를 신뢰성 있게 확인하지 못했다. DOM 흐름 검증과 구분한다.
- 스캔 PDF OCR, HWP 3·암호·배포용 문서, 서식 완전 복원: 지원하지 않는다. 표·줄바꿈은 사용자가 확인한다.

## 다음 실행 단계

1. Docker 화면에서 팀이 가상 자기소개서로 기능을 확인한다.
2. [무료 AI 선택](free-external-ai.md)에 따라 Groq Free Plan 키를 서버 비밀값에 설정한다.
3. [서버 배포 안내](server-deployment.md)에 따라 무료 VM 또는 2GB 이상 VPS를 마련한다.
4. 실제 도메인·팀 접속 해시를 설정해 HTTPS로 배포한다.
5. 실제 모델 출력 품질·응답 시간과 수어 의미를 검토한다.

위 단계에서 필요한 키·서버 계정은 사용자가 직접 준비해야 한다. 실제 채용 접수·지원서 영구 보관 기능은 만들지 않았다.
