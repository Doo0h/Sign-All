# Sign-All (시그널)

청각장애인의 면접 준비를 지원하는 AI 기반 웹 MVP입니다. 컴퓨터공학 전공 학생 4명이 총 8회 활동으로 개발합니다.

## 프로젝트 목표

기업·직무별 면접 질문을 시각적으로 확인하고, 관련 수어 콘텐츠를 참고하여 텍스트로 답변을 연습하며 AI 피드백을 받는 웹 서비스를 만듭니다.

## MVP 범위

1. 자기소개서 AI 분석: 핵심 키워드와 역량 요약
2. 확보한 기업·NCS 자료에 근거한 면접 질문 생성
3. 질문 텍스트와 핵심 키워드 관련 수어 자료 제공
4. 텍스트 답변 입력 및 연습용 AI 피드백

자기소개서 전체의 수어 문법 변환, 3D 아바타, 수어 동작 인식은 이번 MVP 범위에서 제외합니다. 키워드 영상은 질문 전체의 수어 번역이 아닙니다.

## 현재 상태

백엔드 첫 구현을 추가했습니다. Node.js 24.x와 SQLite로 참조자료 조회·임시 세션·분석/질문/피드백 요청 흐름을 실행할 수 있습니다. 기본 demo 모드는 가상 데이터와 규칙 응답이며 실제 AI가 아닙니다. 프론트 화면·실제 원본 샘플 검증·실제 AI 공급자 및 수어 외부 API 검증은 아직 완료하지 않았습니다.

## 시작하기

```bash
git clone https://github.com/Doo0h/Sign-All.git
cd Sign-All
```

3주차 문서는 설계 대안 비교를 보존합니다. 이번 백엔드 구현의 실제 계약·선택 사항은 [구현 계약](docs/backend-contract.md)과 [백엔드 안내](backend/README.md)를 기준으로 확인하세요. 팀의 최종 기술 합의를 의미하지 않습니다.

백엔드는 Node.js 24.x + SQLite를 교체 가능한 구현 기준안으로 사용합니다. 프론트 기술·AI 공급자 등은 후속 결정합니다. 실행은 다음과 같습니다.

```bash
cd backend
npm start
```

다른 터미널의 backend 폴더에서 `npm run smoke` 또는 `npm test`를 실행합니다. 별도 npm 패키지 설치는 필요 없습니다. 실제 계약과 예시는 [backend-contract.md](docs/backend-contract.md)를 참고하세요.

## 협업 제안

- main에서 기능별 브랜치를 만들어 작업합니다. 예: feature/company-api.
- 변경 목적과 확인 결과를 PR에 적고 팀원 검토 후 병합합니다.
- 실제 수행한 활동·구현·검증만 보고서에 기록합니다.

## 데이터와 비밀정보

API 키는 서버 환경변수로 관리합니다. .env, 사용자 자기소개서·답변, 원본 수어 영상은 커밋하지 않습니다. .gitignore는 실수 방지 규칙이며 커밋 전 파일 확인도 필요합니다. 원본 재배포·영상 연결 조건을 확인하고, 오래된 기업 자료를 현재 현황으로 단정하지 않습니다. 현재 구현은 자기소개서·답변·AI 결과를 SQLite에 영구 저장하지 않고 만료되는 메모리 세션에서 처리합니다. 영구 저장의 필요성은 후속 결정합니다.
